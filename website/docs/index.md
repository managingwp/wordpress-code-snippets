A collection of WordPress PHP snippets. Every page documents one snippet: what it does,
its version, its type, and its status.

The snippets were originally written for WP Codebox, but each one works the same as a
mu-plugin, a plugin, or an entry in any snippet manager. Start with
[installing a snippet](./getting-started/install-a-snippet.md) if you are new here, and
read [the header contract](./reference/snippet-headers.md) if you are adding one.
